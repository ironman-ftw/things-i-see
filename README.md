A little Python project about an eye, a universe, and everything in between.

It starts with an eye slowly opening, blinking, and looking around. Then comes the journey through the pupil, past thousands of stars, drifting comets, and into a little heart-shaped nebula.

Built entirely from scratch using Python, NumPy, mathematics, and ASCII characters. No images, no pre-made animations. Just a thought that grew into something much bigger than I initially planned.

## Getting Started

**Requirements:** Python 3.x, NumPy, Tkinter.

```bash
pip install numpy
```

```bash
python eye.py
```
